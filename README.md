Этот форк просто попытка вернуть протокол VMess в "родительский" проект.

С подробным описанием исключенных протоколов, можно ознакомиться на странице "родительского" проекта - https://github.com/Screamshow/xrust/blob/main/docs/RUST-X.md

А также этот форк следует сложившейся структуре папок и файлов оригинального sing-box в создаваемых пакетах для OpenWrt.
