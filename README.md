Этот форк возвращает исключенный из "родительского" проекта протокол VMess.

С подробным описанием исключенных протоколов, можно ознакомиться на странице "родительского" проекта - https://github.com/Screamshow/xrust/blob/main/docs/RUST-X.md

А также, этот форк следует сложившейся структуре папок и файлов у оригинального пакета sing-box для OpenWrt.
